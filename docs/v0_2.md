# FinCore v0.2

This document collects the changes to the v0.1 specification
(fincore_language_specification_v0_1.md). The binding decisions are
numbered in docs/semantics_decisions.md ("v0.2 additions", 58–67); the
runtime side is in docs/runtime_api.md.

## Language additions in v0.2

### `formatTo`: finitist, compile-time-checked formatting

```go
func formatTo(dst []byte, format string, args...) usize
```

`formatTo` writes the formatted text into `dst`, starting at index 0. It
truncates silently at `len(dst)` and returns the number of bytes written,
which is always `<= len(dst)`. The written bytes are always a prefix of the
untruncated output. The function is Total: it never allocates and never
panics. A buffer, a constant format and a byte count are all it needs, so
it fits the fixed-arena style of `compiler/`:

```go
var b [64]byte
n := formatTo(b[:], "mismatched types %v and %v", x.typ, y.typ)
return io.WriteStdout(b[:n])
```

The format must be a constant string. It is parsed and checked against the
arguments at compile time. Each call is then expanded into straight-line
calls on the runtime writer `fincrt.Fmt`, with no format parsing and no
reflection at run time.

#### Directives

```
Directive = "%" { "-" | "0" } [ Width ] Verb | "%%" .
Width     = decimal_digit { decimal_digit } .   // 1 ... 64
Verb      = "d" | "x" | "s" | "c" | "q" | "v" .
```

| Verb | Accepted argument types | Output |
| :--- | :--- | :--- |
| `%d` | every integer type, including named integer types and untyped integer/char constants | decimal |
| `%x` | integers | lowercase hex, no prefix (`-ff` for -255) |
| `%s` | underlying `string` or `[]u8` | the raw bytes |
| `%c` | underlying `u8` (untyped constants are converted to `u8`) | one raw byte |
| `%q` | `string` / `[]u8` | a double-quoted literal: `\n \r \t \\ \"`, `\xHH` (lowercase) for all other bytes `< 0x20`, `0x7f` and `>= 0x80` |
| `%v` | a named type with a Format method; `bool`; integers; `string` / `[]u8` | the method's output; `true`/`false`; decimal; raw bytes |
| `%%` | none | `%` |

- **Width** is the minimum number of bytes, at most 64. By default the
  text is right-justified with spaces. Flag `-` left-justifies. Flag `0`
  pads with zeros after the sign; it is only allowed with `%d` and `%x`
  and has no effect together with `-`.
- **The `%q` output** is always a valid FinCore and Go string literal, so it
  can be used directly when generating code.
- **Untyped constants** get their default type (`int`, `u8` for char
  literals, `bool`, `string`).

#### Format methods: the static "Stringer"

A named type `T` (also a generic instance) that declares

```go
func (t T) Format(dst []byte) usize
```

is printed by `%v` through this method. The method must be Total, have a
value receiver and have exactly this signature. Otherwise `%v` on `T` is an
error; it does not fall back to the underlying type. The checker resolves
the method at compile time, so there is no dynamic dispatch and there are
no interfaces.

The method receives the unwritten rest of the destination and must follow
the same contract: write from index 0, never more than `len(dst)` bytes,
and return the count. A larger result is clamped. A Format method may call
`formatTo` itself:

```go
type Point struct {
	x int
	y int
}

func (p Point) Format(dst []byte) usize {
	return formatTo(dst, "(%d, %d)", p.x, p.y)
}
```

With a width, the padding is computed from the count the method returns.
When the text is right-justified and less room is left than the width, the
method writes into a scratch buffer of `width` bytes. The padding is then
exact, and the result is still the truncated prefix.

#### Evaluation and effects

- `dst`, `format` and all arguments are evaluated left to right before
  anything is written. Each Format method is called once per directive.
- Totality: a `%v` directive that resolves to `T.Format` is a call edge from
  the caller to `T.Format` in the call graph. It takes part in SCC and
  mutual-recursion detection like a direct call. A Format method that
  formats its own type with `%v` is therefore rejected with E4002, and two
  Format methods that format each other are rejected with E4004.
- Scope: `dst` is only borrowed and `formatTo` retains nothing.
- Comptime: `formatTo` works inside `comptime func` bodies with the same
  semantics. Each formatted argument costs one unit of fuel.

### Grammar

No change. `formatTo` is an ordinary call. Its format language is the
directive syntax above, which applies to the constant string value.

### Universe (spec 2.4)

The builtin functions are now: `len`, `cap`, `copy`, `bytesEqual`,
`strBytes`, `bytesToStr`, `formatUint`, `parseUint`, `NewContext`,
`NewScope`, `panic`, **`formatTo`**. Like every predeclared identifier,
`formatTo` can be shadowed by a declaration of the same name.

### Error catalog (spec 11)

There are no new codes. The existing codes are used as follows:

| Code | formatTo diagnostics (position) |
| :--- | :--- |
| `E2002` TYPE_MISMATCH | `dst` not assignable to `[]byte` (dst argument); format not a constant string (format argument); malformed format, i.e. incomplete directive, unknown verb, flags or width on `%%`, width > 64, flag `0` on a verb other than `%d`/`%x` (format argument); argument not of class Value; argument type not accepted by its verb; invalid Format method (argument) |
| `E2003` ARITY_MISMATCH | number of arguments differs from the number of directives (format argument); fewer than two arguments (call) |
| `E2004` INVALID_NIL | untyped `nil` as an argument |
| `E4002` / `E4004` | recursion through Format methods without a measure |

Message texts (identical in finc0 and finc1):

```
not enough arguments in call to formatTo: have 1, want at least 2
wrong number of arguments for format "%d %d" in call to formatTo: have 1, want 2
format argument s to formatTo must be a constant string
invalid format for formatTo: incomplete directive "%-3" at the end of the format
invalid format for formatTo: unknown verb in directive "%3y"
invalid format for formatTo: directive "%3%" cannot have flags or a width
invalid format for formatTo: width in directive "%100d" exceeds 64
invalid format for formatTo: flag 0 in directive "%05q" is only valid with %d and %x
cannot format p (type *Box): formatTo arguments must be Value types
cannot use ok (type bool) as argument for %d in formatTo
cannot use m (type Meters) as argument for %v in formatTo: method Meters.Format must be a total value-receiver method func(dst []byte) usize
```

### Runtime and code generation

Each call is lowered to an immediately called Go function literal over
`fincrt.Fmt` (`Lit`, `Int`, `Uint`, `Hex`, `HexInt`, `Str`, `Bytes`,
`Quote`, `QuoteBytes`, `Byte`, `Bool`, `Dst`/`Advance`). See
docs/runtime_api.md. finc0 and finc1 emit identical Go.
